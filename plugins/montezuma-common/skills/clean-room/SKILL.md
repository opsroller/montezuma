# Clean-room rule

Montezuma 3D reimplements the *gameplay rules* of The Treasures of Montezuma
(Alawar, 2009). Alawar still owns the original's art, audio, code, text and
name. Rules are not copyrightable; everything else is.

## Never

- Copy, extract, trace, resample or "reference closely" any file from the
  original `.ipa` or any other release: sprites, models, sounds, music, fonts,
  level files, strings, code.
- Use the names "The Treasures of Montezuma", "Emily Jones" or Alawar
  branding in shipped content. The project name is **Montezuma 3D**.
- Pull assets from the web unless the license is CC0, CC-BY or MIT-style and
  you record the source and license.

## Always

- Make new assets from scratch, preferably generated by a script committed to
  `tools/` so anyone can regenerate them.
- Add a line to `assets/PROVENANCE.md` for every new asset file or folder:
  path, how it was made (script path, tool, or source URL), license.
- Describe the original only in your own words in `docs/`, as observed
  behaviour (timing, layout, rules), never as copied text.

If you are unsure whether something crosses the line, leave it out and say so
in your PR description.
