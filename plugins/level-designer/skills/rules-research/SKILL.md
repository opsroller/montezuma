# Settling [verify] items

1. Find two independent public sources: a longplay or review video, a
   written walkthrough or FAQ, a store listing, a press review.
2. Record what you saw, in your own words, as behaviour: counts, timings
   (measure from video frame times), layouts, conditions.
3. Replace **[verify]** with the settled rule and a footnote naming the
   sources (title and URL, timestamp for video).
4. If sources disagree or none exists, pick the more playable option,
   mark it **[chosen]** with a one-line reason, and move on.
5. Tell the gameplay engineer about any rule that changed code-relevant
   numbers.

The original's files on archive.org are not a source. The project's cloud
environment blocks archive.org anyway; do not try to work around that.
