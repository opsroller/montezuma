# Third-party notice sources

Notice texts that every build must ship, copied verbatim from upstream.
They are not ours and keep their own licenses; do not edit them.
`tools/release/notices.py` joins them, with godot-cpp's license from
`thirdparty/godot-cpp/LICENSE.md`, into `THIRD-PARTY-NOTICES.txt`.

| File | Source |
|---|---|
| `godot/LICENSE.txt` | https://github.com/godotengine/godot/blob/4.4.1-stable/LICENSE.txt |
| `godot/COPYRIGHT.txt` | https://github.com/godotengine/godot/blob/4.4.1-stable/COPYRIGHT.txt |

Update both when the Godot pin in `tools/release/godot.env` changes.
