## Board theme `temple`: brazier fire (WP-49)

```yaml
asset: themes.temple brazier fire (flame, smoke, embers, heat haze, fire light)
files:
  - game/assets/textures/temple/fx/T_Fire_{Flame,Motion}.png      # 4x4 sheets, build outputs
  - game/assets/textures/temple/fx/hi/T_Fire_{Flame,Motion}.png   # 8x8 sheets, build outputs
  - game/assets/materials/temple/MI_Fire.tres, MI_FireSmoke.tres, MI_Ember.tres, MI_EmberTrail.tres, MI_HeatHaze.tres
  - game/assets/materials/temple/hi/MI_Fire.tres, hi/MI_FireSmoke.tres
  - game/assets/materials/shaders/SH_Fire.gdshader, SH_FireSmoke.gdshader, SH_Ember.gdshader, SH_EmberTrail.gdshader, SH_HeatHaze.gdshader
  - game/assets/models/temple/fx/fire/PF_BrazierFire.tscn
  - game/assets/lookdev/LD_Temple_Fire.tscn, LD_Temple_Fire_Hi.tscn
origin: generated (flipbooks at build time, not committed; materials, shaders and scenes committed)
authors: [technical-artist (Claude)]
created: 2026-10-18
source:
  - tools/assets/fx/gen_fire.py   # numpy + Pillow: 3D gas simulation (fuel, temperature, soot; buoyancy,
                                  # vorticity confinement, MacCormack advection, FFT pressure projection),
                                  # ray-marched side on into flipbook tiles with motion vectors from the
                                  # simulated velocity
  - tools/assets/gen_theme_scenes.py   # materials, PF_BrazierFire and look-dev scenes from temple.json "fire"
  - game/assets/materials/shaders/SH_Fire*.gdshader, SH_Ember*.gdshader, SH_HeatHaze.gdshader (hand-written)
generator:
  params: tools/assets/fx/fire.json (simulation and sheets), tools/assets/themes/temple.json (particles, light)
  seed: 20261018
  version: the commit that last changed tools/assets/
inputs: []                               # no footage, flipbook libraries, scans or third-party files
license: GPL-2.0-or-later
attribution: ""
changes: >
  Replaces the mesh flame (SH_Flame, MI_Flame, SM_Backdrop_Flame.obj, removed) and the four
  Torch omni lights of PF_Environment (now a FlickerLight3D in each PF_BrazierFire).
notes: >
  The work package asked for a Blender fluid simulation. Blender's solver (Mantaflow) could
  not run headless in our pinned environments: the bpy 5.1 and 5.2 wheels ship a manta module
  whose classes lose their base classes (LevelsetGrid has no setConst, every grid argument
  fails to convert), Debian's Blender 4.0 cannot register the manta module, and blender.org
  builds are not reachable from the build machines. So the same physical model runs in our own
  numpy solver, which also needs nothing beyond the numpy and Pillow CI already pins. The
  blackbody colour uses a published 1985 rational fit of the Planckian locus.
  Regenerate with the commands in docs/how-to/tune-the-fire.md.
```
