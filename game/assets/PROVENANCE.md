```yaml
                                  # simulated velocity

  - game/assets/materials/shaders/SH_Fire*.gdshader, SH_Ember*.gdshader, SH_HeatHaze.gdshader (hand-written)

license: GPL-2.0-or-later
attribution: ""
changes: >
  Replaces the mesh flame (SH_Flame, MI_Flame, SM_Backdrop_Flame.obj, removed) and the four
  Torch omni lights of PF_Environment (now a FlickerLight3D in each PF_BrazierFire).
notes: >
  The work package asked for a Blender fluid simulation. Blender's solver (Mantaflow) could
  not run headless in our pinned environments: the bpy 5.1 and 5.2 wheels ship a manta module
  whose classes lose their base classes (LevelsetGrid has no setConst, every grid argument

  builds are not reachable from the build machines. So the same physical model runs in our own
  numpy solver, which also needs nothing beyond the numpy and Pillow CI already pins. The
  blackbody colour uses a published 1985 rational fit of the Planckian locus.
  Regenerate with the commands in docs/how-to/tune-the-fire.md.
```
